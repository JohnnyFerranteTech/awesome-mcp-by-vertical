## Por qué esta lista

Todos los otros directorios MCP ordenan por categoría *técnica* ("bases de datos", "dev tools") y listan todo, incluidos miles de servidores de juguete abandonados. Si construís un agente para un **negocio real**, pensás en verticales: *"tengo una tienda, ¿qué conecto?"*.

Esta lista responde eso. Cada vertical te da los servidores **maduros y en su mayoría oficiales** que vale la pena conectar. `official` = mantenido por el vendor o el proyecto MCP; `community` = tercero activo.

> ⚠️ El ecosistema se mueve rápido — verificá el repo y los permisos antes de usar un servidor en producción.
>
> Mantenido por [@JohnnyFerranteTech](https://github.com/JohnnyFerranteTech). ¿Útil? Una ⭐ ayuda a que otros lo encuentren.

- ☁️ **Cloud e Infra** — AWS, Cloudflare, Azure, Vercel

## Cómo usarla

1. Encontrá tu vertical.
2. Preferí los `official`; tratá los `community` como "verificar antes de confiar".
3. Antes de producción: chequeá que el repo esté activo, mirá qué **permisos** pide el servidor, y aplicá mínimo privilegio.
4. ¿Construís el agente que *usa* estos servidores? Mirá el [Claude Agents Cookbook](https://github.com/JohnnyFerranteTech/claude-agents-cookbook) y [LLM Security Payloads](https://github.com/JohnnyFerranteTech/llm-security-payloads) para endurecerlo.
